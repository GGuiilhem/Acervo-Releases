# Acervo — releases oficiais

Este repositório contém somente os artefatos oficiais de distribuição e atualização do Acervo para Windows.

Cada versão pode incluir:

- `Acervo-setup.msi` — instalador recomendado;
- `Acervo-setup.msi.sig` — assinatura verificada pelo atualizador;
- `Acervo-portable.exe` — versão portátil;
- `latest.json` — manifesto usado pela verificação automática de atualizações.

Os arquivos são compilados e assinados automaticamente pelo fluxo de publicação do projeto. O código-fonte não é armazenado neste repositório.

> Não execute arquivos do Acervo obtidos fora das releases publicadas nesta página.
